# La interfaz de usuario

Al abrir un documento verás estas zonas principales (los nombres pueden variar ligeramente según la versión):

1. **Barra de menús / barra superior**: archivo, edición, documento, capas, selección, vista, ayuda.
2. **Selector de estudios**: cambia entre Píxel, Vectorial y Maquetación.
3. **Barra de herramientas (izquierda)**: mover, seleccionar, rectángulo, texto, pluma, pincel, recortar, zoom…
4. **Barra de contexto**: opciones de la herramienta activa. Cambia constantemente, ¡mírala siempre!
5. **Lienzo**: tu zona de trabajo. Se desplaza con la barra espaciadora + arrastrar.
6. **Paneles (derecha)**: Capas, Color, Muestras, Carácter, Párrafo, Efectos, Estilos, Historial, Navegador.
7. **Barra de estado**: guías rápidas y atajos de la herramienta.

## Paneles imprescindibles

| Panel | Uso |
| --- | --- |
| **Capas** | Ordenar, ocultar, bloquear, agrupar y aplicar máscaras |
| **Color** | Elegir colores en RGB, CMYK u otros modelos |
| **Carácter / Párrafo** | Tipografía, tamaño, interlineado, alineación |
| **Efectos** | Sombras, resplandores, contornos |
| **Transformar** | Posición y tamaño exactos |

## Atajos básicos

| Acción | Windows | Mac |
| --- | --- | --- |
| Deshacer | `Ctrl+Z` | `Cmd+Z` |
| Copiar / Pegar | `Ctrl+C` / `Ctrl+V` | `Cmd+C` / `Cmd+V` |
| Zoom a ventana | `Ctrl+0` | `Cmd+0` |
| Mover lienzo | `Espacio` + arrastrar | `Espacio` + arrastrar |
| Mostrar/ocultar guías | `Ctrl+;` | `Cmd+;` |

## Ejercicio

1. Crea un documento nuevo A4.
2. Dibuja un rectángulo y un texto.
3. Abre y cierra paneles desde el menú **Ver > Estudio**.
4. Cambia entre estudios y observa cómo cambian las herramientas.
