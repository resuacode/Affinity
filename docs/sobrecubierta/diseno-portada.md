# 3. Diseñar la portada y el fondo

## Paso 1: fondo

1. Dibuja un rectángulo que cubra **todo el documento incluido el sangrado**.
2. Rellénalo con un color sólido o degradado coherente con el género del libro.

## Paso 2: imagen de portada

1. **Archivo > Colocar** y selecciona la imagen.
2. Ajusta para que ocupe la zona de portada (y si quieres, continúe por el lomo y la contraportada).
3. Extiende la imagen hasta el sangrado si llega al borde.
4. Usa **Capas de ajuste** (Curvas, Equilibrio de color) para integrarla con la paleta.
5. Opcional: añade una máscara con degradado para fundir la imagen con el fondo.

## Paso 3: paleta y tipografías

- Máximo **2–3 colores** principales. Guárdalos en el panel **Muestras**.
- Máximo **2 tipografías**: una para el título y otra para el texto.
- Comprueba que tengan licencia para uso comercial.

## Paso 4: título y autor

1. Herramienta **Texto artístico** (`T`), clic en la portada.
2. Escribe el título; elige tamaño grande y jerarquía clara.
3. Añade el nombre del autor en menor tamaño.
4. Mejora la legibilidad con una sombra suave, un recuadro semitransparente o contraste de color.

:::tip
Reduce la vista de la portada al tamaño de una miniatura: si el título no se lee, aumenta el contraste o el tamaño.
:::
