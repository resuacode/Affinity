# 2. Crear el documento y las guías

## Paso 1: documento nuevo

1. **Archivo > Nuevo**.
2. Tipo: **Imprenta**. Unidades: **milímetros**. DPI: **300**. Color: **CMYK**.
3. Ancho y alto: los calculados (ej. 406 × 216 mm).
4. Orientación: horizontal.
5. **Sangrado**: 3 mm en todos los lados. Márgenes: 10 mm.

:::warning[📸 Captura pendiente · C12]
Documento de la sobrecubierta. Instrucciones en `CAPTURAS.md`.
:::

## Paso 2: guías de las zonas

Abre **Ver > Gestor de guías** (o arrastra desde las reglas) y coloca guías verticales, midiendo desde el borde izquierdo del documento (con el sangrado de 3 mm incluido):

| Guía | Posición (ej.) |
| --- | --- |
| Inicio solapa trasera | 3 mm |
| Fin solapa trasera / inicio contraportada | 53 mm |
| Fin contraportada / inicio lomo | 193 mm |
| Fin lomo / inicio portada | 213 mm |
| Fin portada / inicio solapa delantera | 353 mm |
| Fin solapa delantera | 403 mm |

:::warning[📸 Captura pendiente · C13]
Gestor de guías. Instrucciones en `CAPTURAS.md`.
:::

## Paso 3: márgenes de seguridad

Añade guías a 5–10 mm dentro de cada zona: el texto importante **nunca** debe cruzarlas, para evitar cortes y pliegues.

:::warning[📸 Captura pendiente · C14]
Guías en el lienzo. Instrucciones en `CAPTURAS.md`.
:::

## Paso 4: nombra y bloquea

Crea una capa «Guías» y bloquéala. Crea capas vacías: **Fondo**, **Imagen**, **Textos**, **Lomo**.

:::warning[📸 Captura pendiente · C15]
Capas de la sobrecubierta. Instrucciones en `CAPTURAS.md`.
:::
