# 5. Revisión y exportación para imprenta

## Lista de comprobación

- [ ] Medidas finales y lomo confirmados con la imprenta.
- [ ] Fondo e imágenes llegan al sangrado (3 mm).
- [ ] Texto importante dentro de márgenes de seguridad.
- [ ] Imágenes a 300 ppp o más.
- [ ] Documento en CMYK; negro del texto fino en solo K.
- [ ] Sin erratas en título, autor y sinopsis.
- [ ] Hueco del ISBN respetado.
- [ ] Fuentes incrustadas o convertidas a curvas.

## Exportar a PDF

1. **Archivo > Exportar**.
2. Formato **PDF**, preajuste **PDF (para imprenta)** o **PDF/X-1a / PDF/X-4**.
3. Activa **Incluir sangrado**. Marcas de corte solo si la imprenta las pide.
4. Resolución 300 ppp, perfil de color el que indique la imprenta.
5. Exporta y revisa el PDF resultante a zoom completo.

## Exportar una vista previa

Exporta también un **PNG/JPG** a baja resolución para compartir en redes o con el cliente.

## Maqueta 3D (opcional)

Imprime la sobrecubierta a tamaño real y pliégala para comprobar visualmente lomo y solapas.

## Para seguir practicando

- Prueba un diseño con solo tipografía.
- Crea una versión para ebook (solo portada, RGB, 1600 × 2560 px).
- Diseña la sobrecubierta de otro género y compara estilos.
